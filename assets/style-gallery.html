PROTOTIPE LOKASI: geometri dasar ini bukan standar kualitas aset/material video final. Selesaikan aset dan aksi, lalu tunjukkan contoh video 8–12 detik untuk persetujuan sebelum render penuh. Gambar ini adalah render statis native Three.js WebGL dari background-worlds.html, bukan gambar AI, foto, atau bukti video HyperFrames selesai. Targetnya 3D bergaya sederhana yang terasa memiliki ruang; bukan fotorealisme. 54 variasi berupa arahan konteks, dengan satu contoh gambar per profil. Untuk preview WebGL langsung, layani folder skill melalui server lokal HTTP; file PNG dan galeri tetap dapat dibuka langsung.
