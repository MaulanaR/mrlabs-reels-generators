# Optional source-video edit with Islamic policies

Use only for explicitly supplied footage to edit, not a style reference. No input is assumed at installation. Set workflow_mode source_video_edit, preserve exact source path/name/hash/streams and inspect actual footage/transcript. Do not substitute an unrelated generated video.

Original recorded speech is not local TTS and needs no Google key. Preservation is conditional on no faces/no music/religious accuracy: there is no presenter/style exemption. Inspect human/animal faces in main shots, photos/screens/reflections/statues/textures and turns. Propose crop, replacement, occlusion or removal so no face remains in the actual final output. A negative prompt/detector alone does not fix footage.

Check embedded music. Supported removal/replacement must be in the approved plan and reviewed by listening for clean intelligible speech. If unavailable, ask for a clean source or approval for Google replacement narration; never keep prohibited music or run local synthesis. No AI tilawah/prophet impersonation. Religious assertions in supplied audio still need verification/correction through `religious-research.md`. Prophet bodies become only abstract light/name markers, never retained silhouettes. Approved portrait crop/contain preserves meaningful action.

## Review before edit

Cache authorized input under `00_source/` or reference its exact provided path without moving/overwriting it. Record real dimensions/fps/duration, rotation/variable-frame-rate issues and audio stream. Reuse matching transcripts; otherwise use available authorized recognition/manual segment review. Do not install heavy speech models or upload private media to a new provider automatically. Recognizing speech is not synthesis. Mark uncertainty instead of inventing words/timestamps.

Keep source/output transcripts separate. Save the timed plan in `03_storyboard.md`: source ID/in/out, transcript excerpt, proposed cuts/order, output interval, corrective sourced information, subtitle/motion/B-roll/SFX, face/music treatment and credit. Preserve order/content unless reviewed changes are approved. Source analysis/acquisition is allowed before approval; production additions, editor import and render wait.

Create `04_edit_review.md` containing actual selected transcript/excerpts, source identities/hashes, cuts/order, all planned additions/treatments and exact credit. Set files.script and review_package.files to that review artifact alongside research/ledger/storyboard/DESIGN. Show it and obtain direct approval. No replacement spoken script/TTS unless requested and included verbatim in review. Technical retiming stays outside frozen approval documents.

## EDL and timeline

Save `09_edit/source-edl.json`: interval ID, source ID/hash, source in/out, output in/out, chosen stream and any deliberately approved speed change. At normal speed lengths agree. Source cue 12s in source 10-18s at output 0-8s maps to output 2s. Split/remove/rebuild cues crossing cuts rather than reuse the old clock.

Subtitles, information, motion, B-roll, original audio and SFX follow this map. HyperFrames picture is muted with separate source audio using matching trim/start/duration. Preserve original speech under supporting B-roll and play it once. Check lip sync, wording and cut tails including final word. No automatic time stretching or generated replacement for convenience.

Complete videos keep at least one real relevant B-roll scene; main presenter footage/pure diagrams do not count. A narrow subtitle-only future request may explicitly override unrelated production scope, with actual user evidence. No default exemption for Islamic projects.

## Acceptance

Reconfirm exact source identity/output before render. Inspect actual encoded content for faithful meaning, approved cuts, no faces through movement/transitions, no music, proper prophet marker, verified additions, portrait crop, synced original speech, readable layers, contextual smooth motion, real B-roll and exact username/CTA. Preserve EDL/source/output transcript versions and evidence/limitations. Source-preservation guidance cannot override Islamic policies; plans/imports are not completed edits.
