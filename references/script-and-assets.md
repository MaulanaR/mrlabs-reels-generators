# Approved script and animated scenes

The verified script or reviewed source transcript determines content. The 18 Islamic background profiles and 54 starting variants supply contextual scene choices, not an inherited demo theme. Read `religious-research.md`, `style-catalog.md` and `visual-direction.md`.

## Review first

Show the full Indonesian narration, cited claims, numbered animated storyboard, prophet treatment, nonmusical SFX and actual credit. For each beat explain what changes on screen and how it clarifies the spoken idea. Freeze research, ledger, DESIGN, storyboard and script in the hashed review package from `production-contract.md`. No new production assets/SFX, imagegen, TTS, animatic or render before approval. Existing previews/supplied input may be inspected and drafts written before approval. Reuse unchanged valid approval on resume; material visual/story changes return to review.

## Roles

- Narrator reads the exact approved Indonesian explanation/meaning via Google; no AI tilawah, invented prophet dialogue/impersonation or local synthesis.
- HyperFrames builds contextual editable objects, diagrams, environments, lighting and scene transitions tied to actual narration. Build the main world as solid true 3D with depth, light/shadow and purposeful camera/object motion, using the visual grammar in `reference-analysis.md`. Diagrams and CSS depth are secondary overlays, not a fallback main scene.
- No B-roll role, internet-footage search or minimum supporting clip. An entirely authored animated video is the intended output. Avoid static wallpaper with captions or a stock-photo slideshow replacing animated explanation.
- Optional fonts/models/textures/illustrations support an approved scene only; see `scene-assets.md`. Start with native 3D geometry/materials; SVG is reserved for secondary labels/diagrams. Imagegen is not a required step or an excuse to build cutaway sequences.
- Prophet scenes use contextual background plus abstract light and a centered verified editable name, never a human outline/body/face or literal appearance claim.
- SFX is contextual nonmusical library audio; no soundtrack/melodic rise/tonal bed.

Record ordered scene IDs, narration/claim IDs, setting, background profile/variant and context reason, light/weather/objects, visual purpose, action, actual motion method, camera/object changes, transitions, measured audio interval, editable component IDs and any necessary resources in `06_scene_assets.json`. During writing, timings may be labelled estimates and resource paths pending. Do not invent completed assets or render success. After audio exists, resolve actual timing and bindings without rewriting the approved meaning.

Inspect actual scene content, no-face/prophet rules, portrait framing, readable text and motion. Repair the failed scene without changing an approved religious claim to fit an attractive visual.
