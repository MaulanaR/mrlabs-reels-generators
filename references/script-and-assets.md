## Roles

- Narrator reads the exact approved Indonesian explanation/meaning via Google; no AI tilawah, invented prophet dialogue/impersonation or local synthesis.
- HyperFrames builds contextual editable objects, diagrams, environments, lighting and scene transitions tied to actual narration. Prioritize smooth useful 3D; use supported Three.js when true geometry/camera is needed. Record CSS depth honestly as 2.5D.
- No B-roll role, internet-footage search or minimum supporting clip. An entirely authored animated video is the intended output. Avoid static wallpaper with captions or a stock-photo slideshow replacing animated explanation.
- Optional fonts/models/textures/illustrations support an approved scene only; see `scene-assets.md`. Start with native geometry/SVG/materials. Imagegen is not a required step or an excuse to build cutaway sequences.
- Prophet scenes use contextual background plus abstract light and a centered verified editable name, never a human outline/body/face or literal appearance claim.
- SFX is contextual nonmusical library audio; no soundtrack/melodic rise/tonal bed.
